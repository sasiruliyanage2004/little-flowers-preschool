A complete, beautiful, and production-ready website for **Little Flowers Preschool**, established in **2010** in Makola South, Sri Lanka. Designed to balance emotional connection with parents, early childhood imagination, and a world-class educational presence.

---

## 🌟 Key Highlights

- **Bilingual Experience:** Seamless English & Sinhala (`Noto Sans Sinhala`) switcher with client-side persistence.
- **Authentic School Media:** Features real photographs of the children in their official school uniform and courtyard video footage.
- **Preserved Official Statements:** Includes the official Sinhala Vision & Mission alongside professional English translations.
- **Complete Page Architecture:**
  - `Home` (`/`): Immersive Hero, 2010 Heritage Timeline, Welcome, Vision/Mission, 6 Developmental Domains, Learning Through Play, Gallery preview, Video showcase, and Parent CTA.
  - `About Us` (`/about`): Preschool story, 14+ years of heritage, leadership under Mrs. Indrani Wettasinghe, educational philosophy, and core values.
  - `Our Learning` (`/learning`): In-depth 6 early childhood development domains, daily routine (08:00 AM – 12:00 PM), and nurturing individual talents.
  - `Gallery` (`/gallery`): Responsive masonry grid with category filters, full-screen lightbox, and YouTube video showcase.
  - `Admissions` (`/admissions`): 4-step enrolment process, interactive admission enquiry form with phone validation, and FAQs.
  - `Contact` (`/contact`): Verified direct phone, WhatsApp link, embedded Google Map, directions button, and contact form.
- **Production Performance:** 100% Static Site Generation (SSG) with `next/image` optimization and zero TypeScript/build errors.
- **SEO & Accessibility:** Preschool JSON-LD structured data, dynamic `sitemap.xml`, `robots.txt`, and OpenGraph metadata.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org) (v18.17 or higher recommended)
- `npm` or `yarn` / `pnpm`

### Quick Start (Windows)
Double-click `start.bat` in the project root. It will automatically check dependencies, start the server, and open `http://localhost:3000` in your default browser.

### Manual Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/little-flowers-preschool.git
   cd little-flowers-preschool
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser.

4. **Production Build:**
   ```bash
   npm run build
   npm run start
   ```
